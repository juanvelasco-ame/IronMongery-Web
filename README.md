# IronMongery Web

## Descripción del proyecto

IronMongery Web es un proyecto académico desarrollado en la asignatura Desarrollo de Software I. Consiste en diseñar un sitio web para una ferretería, con el propósito de organizar y presentar información sobre productos, categorías, proveedores, clientes, inventario y ventas.

El sistema está pensado para manejar diferentes roles de usuario, como administrador, vendedor y cliente, cada uno con funciones específicas.

## Objetivo general

Desarrollar una página web que permita presentar la información de una ferretería de manera organizada, utilizando HTML y CSS, y aplicar los conocimientos básicos de Git y GitHub para controlar las versiones del proyecto.

## Tecnologías utilizadas

- **HTML5:** permite crear la estructura de las páginas web.
- **CSS3:** permite definir los colores, la distribución y los estilos visuales.
- **Git:** permite llevar un historial de los cambios realizados.
- **GitHub:** permite almacenar el repositorio y compartir el proyecto.

## Estructura del proyecto

- `index.html`: página principal del sitio web.
- `estilos.css`: archivo que contiene los estilos visuales.
- `pagina1.html`: página dedicada a mostrar ejemplos de productos de ferretería.
- `pagina2.html`: página con información del proyecto y sus objetivos.
- `README.md`: documento que describe el proyecto y sus archivos.
- `archivo.txt`: archivo utilizado durante la práctica de Git.
- `.gitignore`: indica qué archivos o carpetas deben excluirse del seguimiento de Git.

## Roles propuestos

- **Administrador:** encargado de gestionar la información y supervisar las operaciones.
- **Vendedor:** encargado de apoyar la atención al cliente y el proceso de ventas.
- **Cliente:** usuario que consulta los productos y la información disponible.

## Ejecución del proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir `index.html` en un navegador web, o ejecutar Apache desde XAMPP y visitar la dirección local del proyecto.

## Control de versiones con Git

Durante la práctica se utilizan los siguientes comandos:

- `git clone`: descarga una copia del repositorio.
- `git add .`: prepara los archivos nuevos y modificados.
- `git commit -m "mensaje"`: registra los cambios con una descripción.
- `git push`: sube los cambios al repositorio remoto.
- `git pull`: actualiza la copia local con los cambios del repositorio remoto.
- `git config --global`: configura el nombre y el correo utilizados para identificar los commits.
