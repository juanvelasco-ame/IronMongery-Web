¿Quiénes somos?

IronMongery Web es un proyecto académico de Desarrollo de Software I enfocado en la gestión de una ferretería.

Objetivo del proyecto

Diseñar un sistema web que permita organizar la información de productos, categorías, proveedores, clientes, inventario y ventas.

Roles del sistema

Administrador: gestiona la información y supervisa las operaciones.

Vendedor: apoya el proceso de ventas y la atención al cliente.

Cliente: consulta los productos y la información disponible.
